# Atelier desktop visual system

Updated 2026-11-22. Light fashion publication, with local Libre Baskerville typography, warm ivory #f3efe7, ink #272c26 and cinnamon #725641. Keep the Atelier wordmark and all existing garment photography.

## Composition
The desktop home is a ruled publication spread: large masthead, asymmetric headline and photograph, a measured category directory, open product frames and a dark staggered lookbook spread. A code-drawn radial line mark and vertical margin typography add character without new imagery. Catalog pages use a compact heading and filter strip so the first garment names and prices appear above the fold.

## Controls
Rectangular, labelled shopping controls; visible save states; open garment name/price rows and detail actions. Product pages, configurable outfits, saved pieces, bag, checkout and administration retain their current behavior. Desktop type uses a display serif for editorial headings and practical sans for controls. The font and OFL license are hosted locally.

## Boundaries and evidence
This pass targets desktop screens only. Existing catalog, stock, cart and payment rules remain authoritative. No new photography was generated. Images are synthetic portfolio imagery; optional Stripe test integration and other demo limitations remain documented in README.
